# Riwayat perubahan

## 0.1.0 — 3 Oktober 2026

- Rilis awal template skripsi LaTeX komunitas untuk FILKOM UB.
- Kelas `filkomskripsi.cls`, berkas utama `skripsi.tex`, dan pengaturan identitas melalui `metadata.tex`.
- Halaman awal, abstrak Indonesia/Inggris, daftar isi/gambar/tabel/lampiran, enam bab nonimplementatif, referensi, dan lampiran generik.
- Opsi font otomatis, Carlito untuk preview yang dapat direproduksi, dan Calibri untuk build official dengan font legal dari pengguna.
- Skrip Python untuk preview, official, check, dan clean; target Make untuk preview, official, check, serta test.
- Panduan lokal, Overleaf, bibliografi, penyesuaian struktur implementatif, dan pemecahan masalah.
- Lisensi kode/dokumentasi LPPL 1.3c atau lebih baru, keterangan aset terpisah, serta template issue dan pull request.

Nama build official menunjuk konfigurasi font; rilis ini bukan publikasi atau pengesahan resmi Universitas Brawijaya. Persetujuan akademik dan kepatuhan naskah mengikuti ketentuan yang berlaku bagi penulis.
